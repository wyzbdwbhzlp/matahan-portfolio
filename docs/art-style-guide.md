# Matahan Portfolio Art Style Guide

这份文档用于沉淀个人网站的美术方向，后续新增页面、组件、博客模板或视觉重构时，优先按这里统一风格。对应的 CSS 变量来源是 `src/styles/design-tokens.css`。

## 一句话风格

极光像素复古游戏终端。

它应该像一个独立游戏开发者的个人宇宙入口：有像素游戏的硬边 UI，有极光夜空的浪漫感，有 CRT/终端的开发者气质，也有 Game Jam 式的可玩彩蛋。

## 关键词

- Pixel Art
- Indie Game
- Aurora Night
- CRT Glitch
- Retro Terminal
- Celeste-like Mood
- Game Developer Portfolio

## 视觉支柱

1. 像素游戏感

   使用硬边框、无圆角、像素字体、方块阴影、HUD 式标签、8-bit 小装饰。按钮和卡片要像游戏菜单，而不是 SaaS 卡片。

2. 极光夜空

   Hero 和沉浸式区域使用深空蓝黑作为底，辅以极光绿、青色、紫色。氛围应该冷冽、清澈、有雪山和夜空感。

3. 复古终端

   使用单色终端文案、命令行符号、扫描线、轻微故障、Konami Code 彩蛋。它是“开发者终端”，不是赛博朋克霓虹夜店。

4. 高对比纸面内容

   内容区以纸白和黑色粗边框承载，绿色硬投影作为强调。阅读区域要清楚，不能让特效压过信息。

## 色彩

| 用途 | Token | 色值 | 使用建议 |
| --- | --- | --- | --- |
| 主强调 | `--aurora-green` | `#4ade80` | CTA、边框 hover、发光、进度条 |
| 辅助极光 | `--aurora-teal` | `#2dd4bf` | 极光渐变、阴影层次 |
| 冷光 | `--aurora-cyan` | `#06b6d4` | 少量科技感点缀 |
| 梦境色 | `--aurora-violet` | `#8b5cf6` | 次按钮、未来节点、故障层 |
| 深空底 | `--sky-deep` | `#050b1a` | Hero、小游戏、全屏沉浸层 |
| 主文字 | `--ink-900` | `#0a0a0a` | 正文强文字、粗边框 |
| 纸白 | `--paper-50` | `#fafaf7` | 内容区背景 |
| 雾白 | `--aurora-mist` | `#e6f0e0` | 深色背景上的说明文字 |

色彩比例建议：深空或纸白占 70% 以上，黑色结构线占 15%，极光绿/青/紫作为 10% 左右的强调。不要让页面变成大面积单一绿色，也不要把紫色渐变铺满全页。

## 字体

| 场景 | Token | 建议 |
| --- | --- | --- |
| 英文品牌/大标题 | `--font-display` | 使用 Orbitron，适合 WHH、LOGO、强身份标题 |
| 像素标题和标签 | `--font-pixel` | 用于 section title、HUD、按钮、小标签 |
| 代码和终端 | `--font-mono` | 用于命令行、项目编号、技术栈 |
| 正文 | `--font-body` | 博客和长文阅读优先保证可读性 |

字体使用原则：Hero 可以夸张，卡片和内容区要收紧。像素字体不适合大段正文，长段中文优先使用更可读的字体。

## 构图和布局

- Hero 第一屏必须明确传达人物身份和游戏开发者气质。
- 主要 section 使用完整横向区域，不把整个页面都包进大卡片。
- 卡片只用于作品、时间线节点、技能块等重复内容。
- 卡片风格保持：白底、黑色 4px 边框、硬投影、无圆角。
- 内容宽度优先使用 `--content-max`，长文使用 `--prose-max`。
- 移动端优先保证文字不溢出，像素字体要减少字号和字距。

## 组件风格

### 按钮

按钮要像游戏菜单项：硬边、明确 hover、带轻微位移或投影变化。

优先组合：

- 主按钮：黑底白字，hover 变极光绿。
- 次按钮：白底黑字，hover 变极光紫。
- 图标或箭头可以使用简单线性 SVG，保持像素/终端气质。

### 卡片

卡片是“游戏 cartridge / terminal panel”感觉：

- `background: var(--card-bg)`
- `border: var(--card-border)`
- `box-shadow: var(--card-shadow)`
- `border-radius: var(--radius-pixel)`
- hover 可使用 `var(--card-shadow-hover)` 和轻微上移。

### 标签

标签用于技术栈、奖项、状态。形状硬边，文字短，避免一整句塞进标签。

### 时间线

时间线表达成长轨迹，节点可以发光，但线条本身保持克制。当前节点用极光绿，未来节点用紫色。

## 动效

动效应该像“游戏系统启动”，不是普通网页过场。

可用动效：

- 打字机文字
- 极光缓慢漂移
- 像素雪
- CRT 扫描线
- 卡片 3D hover
- 技能条 step 动画
- Konami 彩蛋和小游戏入口

避免：

- 大面积弹跳
- 过度透明毛玻璃
- 无限强闪烁
- 和阅读内容抢注意力的背景动画

## 图像和装饰

当前视觉核心不是照片墙，而是代码生成的像素场景和 UI 装饰。后续如果加入项目图，应优先使用真实游戏截图、像素化封面、GIF 或短视频预览，不要使用泛泛的 stock 图。

装饰元素可以包括：

- 像素雪
- 山体剪影
- 星座线
- 终端命令
- 游戏 HUD
- 小型 sprite

## 文案气质

文案要兼具开发者的冷静和独立游戏作者的浪漫。

适合：

- “用代码写诗，用逻辑造梦。”
- “Selected Works”
- “developer_mode_unlocked”
- “Games are the highest form of art.”

不适合：

- 过度商务化的“高效赋能解决方案”
- 过度营销化的“打造极致体验”
- 和个人作品无关的空泛口号

## Do

- 优先复用 `src/styles/design-tokens.css` 中的变量。
- 新页面先确认是否属于深色沉浸页、纸白内容页、博客长文页。
- 保持黑色粗边框、硬投影、像素/终端小标签这套 UI 语言。
- 控制特效密度，让内容永远比装饰更清楚。
- 新增博客/About 样式时，让它们向首页靠拢，而不是继续保留 starter 风格。

## Don't

- 不要使用大圆角玻璃卡片作为主风格。
- 不要加入大面积紫蓝渐变背景。
- 不要把像素字体用于长段正文。
- 不要使用通用科技蓝 SaaS 风。
- 不要新增和游戏开发者身份无关的装饰。
- 不要让页面所有元素都发光，发光只用于状态和强调。

## 新模块检查清单

- 是否能用一句话说出它属于“极光像素复古游戏终端”？
- 是否复用了 `design-tokens.css` 中的色彩、阴影、边框或字体？
- 是否保留了硬边 UI，而不是默认圆角卡片？
- 移动端中文和英文是否都不溢出？
- 动效是否服务于“游戏系统感”，而不是单纯炫技？
- 页面是否还有 starter 占位内容或无关外链？
